# Каталог из Figma

В `public/assets/source-manifest.json` зафиксированы все 40 вариантов объектов и шесть фоновых плоскостей. Цвета трёх палитр взяты из оригинальных плашек. Файл содержит имена, реальные пропорции и ID узлов Figma.

Окончательные ID и названия отличаются от двух предварительных: **wallet — Кошелёк**, **pen — Ручка**. Используйте их в каталоге, семантике, пресетах, тестах и документации.

Исходная цветовая разметка компонентов соответствует `lavender`. Белый в самих SVG записан как `white`. Фоновые варианты содержат только `#D7CDF5` и `#7864D7`. Цветные варианты также используют `#AA9BF0`, `#181817`, `#F9ECB0`, `#F9A3AA`, `#FFE3E1` и `white`. Цветовые роли надо преобразовывать напрямую из исходной палитры, без повторного перекрашивания уже преобразованного SVG.
